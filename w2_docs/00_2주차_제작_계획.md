## 4. 빈칸 원칙

- 비우는 곳: 함수 본문의 핵심 줄과 `a2_env_cfg.py`의 등록 줄. 숫자·단어 채우기가 아니라 몇 줄을 직접 작성하는 수준.
- 남기는 것: 함수 이름, 역할, 입출력 shape, 수식, 쓸 변수의 위치 힌트, 계열마다 풀이 예시 함수 하나.
- 힌트 주석: 한글 개조식. 변수·필드 이름은 영어 원문 그대로. 줄바꿈으로 읽기 쉽게.
- 오전 2시간 구성

| 구간 | 난이도 | 진행 |
|---|---|---|
| 1교시 | 기본 | 풀이 예시를 같이 본 뒤 같은 형태를 직접 작성 |
| 2교시 | 중간 | 변수 위치를 스스로 찾아 작성, 계열이 끝날 때마다 강의자 확인 |
| 끝 | 도전 문제 1개 | 각자 풀고, 15시에 정답 확인 |

- 학습은 11시에 시작. 15시까지 최대 4시간. 13–15시 개별 학습에는 강의자가 개입하지 않음.
- 도전 문제도 그날 학습에 들어가는 항목으로 냄 (11/19 확정): 화 `track_lin_vel_xy_exp`, 수 `joint_position_penalty_command_aware`, 목 `feet_air_time`. 11시 학습은 각자의 답으로 돌고, 틀린 경우 15시 제어기 테스트는 미리 학습한 checkpoint로 진행. 항목별 설계는 `빈칸_설계서.md`.
- `w2_edu`가 빈 상태로도 학습이 돌아야 하므로 설계 때 확인할 것
  - 미작성 항목이 조용히 0을 내면 수강생이 모름. 점검 스크립트가 미작성 목록을 출력해야 함
  - `lin_vel_cmd_levels` curriculum이 reward 이름 `track_lin_vel_xy`를 참조함
  - `__post_init__`의 `reward_type_dict`, `obs_type_dict`가 항목 이름을 나열함
  - `tests/smoke_a2.py`는 225/247 차원을 전제로 함
  - `action_smoothness`는 `JointPositionActionWithHistory`, `base_height`는 `height_scanner`가 있어야 함

## 6. 강의 자료 구성 요점

- 서식은 `PPT_디자인_가이드라인.md`와 1주차 실습 장 형식을 따름. 제작 틀은 `덱_제작_스크립트` (ppt_lib, COM mutex).
- 1주차에 있는 내용은 다시 넣지 않고 "1주차 N일차 ○○ 장"으로 참조.
- 화요일에 "critic에 왜 다른 관측을 주는가" 한 장 추가 (1주차 내용 참고, 오후 Actor-Critic 이론으로 이어짐).
- 그림은 직접 제작: reward 커널 모양, body/world frame, projected gravity, obs history, air time, foot clearance, PD gain과 motor DR. 저장 위치 `2주차_자료/그림/`.
- A2 정보(관절 이름·순서, 기본 자세, Kp 25/Kd 0.5, Isaac Lab과 MuJoCo·SDK 사이 관절 순서 대응)는 `edu_rl_lab/assets/a2.py`, `edu_rl_mjlab`의 `deploy.yaml`·`doc/sim2sim.md`에서 가져옴.
- 금요일: 배포 절차 점검표, 조작 순서(Passive → FixStand → Velocity), 안전 수칙, 화·수·목 제어기 비교 관찰표, 2주차 정리. 월요일 성현 자료와 겹치지 않게 점검표 수준으로.
