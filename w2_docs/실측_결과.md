- Isaac Lab이 conda가 아니라 Docker 컨테이너에 있음. `$KEEP/bin/python` 대체 스크립트가 `python scripts/...`, `python tests/...`를 컨테이너의 `/workspace/isaaclab/_isaac_sim/python.sh`로 넘김 (GPU는 환경 변수 `GPU`). 작업 트리는 컨테이너에 마운트된 `~/ws/edu_rl_lab_ws/` 아래
